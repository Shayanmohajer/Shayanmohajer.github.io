# Shayan Mohajer Hamidi Academic Homepage

This repository contains the static source for the GitHub Pages website at:

- <https://shayanmohajer.github.io/>

## Structure

- `index.html` - semantic single-page layout
- `styles.css` - responsive custom styling
- `script.js` - publication rendering and filtering
- `assets/Shayan_Mohajer_Hamidi_CV.pdf` - downloadable CV

## Deployment

The site is deployed through the existing GitHub Pages workflow in `.github/workflows/static.yml`.
